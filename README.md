# Dark Photo Portfolio

## Development

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

## Deploy to GitHub Pages

1. Ensure this repo is named `Portfolio` under `Harsh000830`.
2. Build and deploy:

```sh
npm install
npm run build
npm run deploy
```

3. In GitHub, open **Settings → Pages** and set source to:
   - **Branch:** `gh-pages`
   - **Folder:** `/ (root)`

Your site URL will be:

`https://harsh000830.github.io/Portfolio/`
